# Public site design

Preserve the extension's dark neutral / blue identity and system typography. Homepage mode: Read, a concise product overview and data-handling explanation. Privacy page mode: Read, a narrow single-column document. Use typography and horizontal rules rather than decorative cards or unverifiable metrics. Responsive stacked layout below 640px. No imagery is needed; no sensitive screenshots or simulated user records. Visible keyboard focus, skip link, semantic headings and restrained high-contrast links.
